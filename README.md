# AVPL遨遊宇宙：AI教師引導下的宇宙物理的四大基本力探索

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | AVPL 大廳：學生登錄、九間入口、完成狀態、全部學習歷程 PDF、行為資料 JSON |
| `gravity-1-observe.html`、`gravity-2-pattern.html`、`gravity-3-cause.html` | 重力與軌道：觀測／規律／原因 |
| `em-1-accident.html`、`em-2-pattern.html`、`em-3-application.html` | 電流磁效應：意外／規律／應用 |

整個資料夾直接放進 GitHub Pages repo 即可（九間共用同一網域，紀錄才會互通）。
在網址後加 `?debug=1` 可在畫面上方即時看到目前的行為代碼，方便研究者校正編碼。

## 每一間的結構（Zone）
- 本展間關卡（原 Zone 1／2／3 之一）：展板、3D 模型、實驗控制台、人物 NPC
- Zone 4 反思展區：完成關卡後開啟；只保留與本間相關的紀錄牆；反思札記（3 題通用＋1 題遷移題）；匯出學習歷程 PDF

| 代碼 | 行為 | 主要發生位置 | 怎麼判定 |
|---|---|---|---|
| RD | 閱讀展板 | 關卡區展板、NPC | 7 m 內注視展板；敘事型對話框；「交談／讀」互動 |
| EX | 操作實驗 | 關卡區控制台 | 側欄按鈕、滑桿、「抄錄」互動、E2 的 R 鍵 |
| AI | AI 對話 | 全區 | 開啟 AI 面板、輸入中、送出提問、請求回饋 |
| NV | 空間導航 | 全區 | 移動＞0.6 m／秒、大幅環顧、傳送 |
| OB | 觀察模型 | 關卡區 3D 模型 | 靜止注視模型（最多 30 秒） |
| RF | 反思回顧 | 關卡區問答、Zone 4 | 問題型對話框作答（POE、概念題）、反思札記、注視紀錄牆、匯出 PDF |
| ID | 閒置 | 全區 | 10 秒無輸入、離開分頁 |

主動事件立即編碼並維持 4 秒；被動狀態每秒取樣、連續 2 次一致才切換。連續相同代碼合併為一個段落。

## LSA
1. 學生在大廳按「下載行為資料」→ 交給老師（或老師在同一台電腦按「讀取這台裝置的紀錄」）
2. `lsa.html` 匯入多個 JSON，輸入或匯入後測分數（CSV：學號,分數）
3. 選分組（中位數／前後 27%）、序列單位（行為段落／5 秒取樣）、顯著門檻（1.96／2.58／Bonferroni）
4. 看「研究假設檢核」：H1 RD→AI→EX→RF、H2 NV⇄OB、H3 AI→EX
5. 匯出 z 值表、轉移次數表、序列 CSV、GSEQ SDS 草稿

計算：行為段落模式的對角線是結構零，期望次數用 IPF（準獨立模型）估計，已用 statsmodels Poisson GLM 交叉驗證，數值一致；z 值採 Allison & Liker 調整後殘差公式（結構零下為近似）。正式論文建議以 GSEQ 5 複核。

「載入模擬示範資料」是我依假設設計的馬可夫鏈假資料，只用來檢查流程，不能當結果引用。
